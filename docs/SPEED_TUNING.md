# 적 이동 속도 실험

`speed_changes` 브랜치의 오른쪽 **ENEMY SPEED LAB** 패널에서 적 종류별 속도를 실시간으로 조절할 수 있습니다. Tracker는 코드에서 `Chaser`라고 부르는 보라색 BFS 추격 적입니다.

## 기본값과 단위

| 슬라이더 | 적 종류 | 기본 속도 |
|---|---|---:|
| WANDERER | 주황색 일반 적 | 1.65칸/초 |
| TRACKER / CHASER | 보라색 추격 적 | 2.15칸/초 |
| ARMORED | 장갑 적 | 1.40칸/초 |
| SWIFT | 청록색 고속 적 | 2.70칸/초 |

모든 슬라이더 범위는 **0.00~6.00칸/초**, 조절 간격은 **0.05칸/초**입니다. `0.00`은 해당 종류의 적만 정지시킵니다. 플레이어의 기본 이동 속도는 3.00칸/초이며, 현재 플레이어 속도도 패널에 표시합니다.

## 사용 방법

1. Space로 게임을 시작합니다. STAGE 준비 화면에서도 조절할 수 있습니다.
2. 오른쪽 트랙을 클릭하거나 손잡이를 드래그합니다. 같은 종류의 모든 적에 즉시 적용합니다.
3. 움직임을 보며 조절하거나, `P`로 게임을 일시정지한 뒤 값을 바꾸고 다시 `P`로 재개합니다.
4. `RESET ALL`을 누르면 네 종류를 모두 기본값으로 복원합니다. 트랙의 가는 표시선도 기본값 위치를 나타냅니다.
5. `F6`으로 패널을 숨기거나 다시 표시합니다. 숨겨도 설정한 속도는 유지합니다.

도움말·랭킹·홈·게임 종료 결과 화면에서는 슬라이더 입력을 받지 않습니다. 드래그 중 포커스를 잃거나 패널을 닫으면 드래그를 해제합니다. 창 크기가 달라도 화면 비율과 마우스 클릭 위치가 함께 맞춰집니다.

## 설정 유지와 랭킹

- 선택한 속도는 프로그램이 실행되는 동안 피격, 다음 스테이지, F3 연습 장면, F4 새 캠페인을 지나도 유지합니다. 나중에 등장하는 종류의 적에도 적용합니다.
- 프로그램을 종료했다 다시 켜면 기본값으로 시작합니다. 파일에 프리셋을 저장하는 기능은 아직 없습니다.
- 실제 속도를 한 번이라도 변경한 판은 **SPEED TUNING / UNRANKED**로 표시하며 랭킹에 기록하지 않습니다. 점수 계산과 3개 스테이지 진행은 유지합니다.
- 같은 판에서 기본값으로 돌려도 테스트 표시를 유지합니다. 기본값으로 정상 플레이하려면 **RESET ALL → F4**로 새 캠페인을 시작합니다.
- 기본값 손잡이를 그대로 클릭하거나 패널만 열고 닫는 동작은 정상 플레이를 테스트 판으로 바꾸지 않습니다.

## 비교 실험 제안

가장 적절한 속도는 직접 플레이하면서 비교하는 편이 좋습니다. 한 번에 한 종류만 변경하고 나머지는 기본값으로 유지하면 차이를 구분하기 쉽습니다. 같은 설정으로 여러 번 플레이하고, 아래 항목을 함께 적어 두는 방식을 권합니다.

| 설정 | 일반 | Tracker | 장갑 | 고속 | 생존 시간 | 클리어 시간 | 잃은 목숨 | 체감 난이도 |
|---|---:|---:|---:|---:|---|---|---:|---|
| 기본값 | 1.65 | 2.15 | 1.40 | 2.70 | | | | |
| 실험 A | | | | | | | | |
| 실험 B | | | | | | | | |

추가하면 유용한 기능은 다음과 같습니다.

- **같은 맵·시드로 재시도:** 현재 F4는 새 맵을 고릅니다. 같은 맵, 적 배치, 플레이어 능력으로 재시도하면 속도 차이를 더 공정하게 비교할 수 있습니다.
- **실험 기록 자동 저장:** 설정값과 생존 시간·클리어 시간·피격 횟수를 CSV로 남겨 여러 판을 비교합니다.
- **느림·기본·빠름 프리셋과 설정 내보내기:** 비교할 값을 빠르게 바꾸고, 최종 선택한 수치를 다음 실행에서도 재사용합니다.

이 세 가지는 추가 제안이며 현재 구현에는 포함하지 않았습니다.
