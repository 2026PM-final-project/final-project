# 3분 이내 데모 동선

일반 플레이와 F3 연습 장면을 함께 사용한다. 연습 장면은 화면에 PRACTICE / UNRANKED로 표시되며 일반 게임과 같은 규칙 코드를 실행한다. F4는 새 일반 캠페인 시작이고, F3은 장면을 초기화하면서 다음 장면으로 이동한다.

| 시간 | 조작과 보여 줄 내용 |
|---|---|
| 0:00~0:20 | 실행 → 1. 3D 조명, 질감 있는 벽, 플레이어·적·목숨·화력·용량 HUD. D로 (2,1) 이동, Space 설치, A로 (1,1)에 돌아온 뒤 S로 (1,2)에 피하기. 방금 설치한 폭탄으로 되돌아갈 수 없는 점 설명 |
| 0:20~0:35 | F3 1회: Chain. 2.5초 뒤 A→B→C→D가 같은 틱에 폭발. 단단한 벽에서 차단, 오른쪽 부서지는 벽 파괴. 큐 기반 BFS 연쇄반응 설명 |
| 0:35~0:55 | F3: Chase. F2 경로 표시 확인. 보라 적이 8칸 이내에서 최단 경로를 따라옴. 움직여 거리를 벌리면 경로가 사라지고 일반 이동으로 복귀 |
| 0:55~1:20 | F3: Items. 출발점에서 D로 (2,1)에 이동하고 Space → A로 (1,1) → S로 (1,2)까지 피하기. 2.5초 뒤 (3,1)의 Fire 노출. 화염 소멸 후 획득하면 FIRE 1→2. (1,3)=Bomb, (3,3)=Speed도 숨겨져 있음 |
| 1:20~1:45 | F3: Exit. (13,9)의 벽 아래 출구. 그 왼쪽 (12,9)에 폭탄을 두고 (11,9) → (11,8)로 꺾어 피하면 출구를 드러낼 수 있음. 적이 남으면 LOCKED, 모두 죽으면 OPEN. 열린 출구 진입으로 클리어 |
| 1:45~2:10 | F3: Specials. 시작 폭탄은 PIERCE. (3,5)에서 설치 후 (3,3) → (2,3)으로 꺾어 피하면 (5,5),(7,5) 벽을 관통. Q로 REMOTE 선택, 설치 후 E로 기폭. 강철 적의 HP 점 두 개, 청록 고속 적 설명 |
| 2:10~2:25 | F3: Life. 추격 적과 접촉해 목숨 감소, 출발점 복귀, 짧은 무적 확인. 패배 시 OUT OF SPARKS |
| 2:25~2:45 | Esc → 2. P1 WASD/Space, P2 방향키/Enter를 직접 보여 주기. 서로 독립적인 FIRE/BOMBS/SPEED HUD와 폭탄 종류 변경 |
| 2:45~2:55 | Tab으로 저장된 로컬 랭킹 구조 설명. F1 도움말, M 음소거, 3개 스테이지 및 최종 승리 조건, README의 테스트 결과 언급 |

키를 계속 누르면 칸 중심을 지나 다음 칸으로 이동한다. 짧게 눌러도 이미 시작한 한 칸 이동은 중심까지 마무리된다. 폭탄과 적을 피해 안전한 모퉁이로 이동할 시간을 확보한다. 시연 중 멈추려면 P 또는 F1을 사용한다.

첫 실행 랭킹은 비어 있다. 일반 캠페인의 게임오버 또는 3스테이지 최종 승리를 마치면 자동으로 기록되며, 연습 결과는 기록되지 않는다. 실제 기록 없이 샘플 점수를 넣어 채점 결과처럼 보여 주지 않는다.
