# 검증 기록

검증일: 2026-10-28 (Asia/Seoul). Windows x64, GCC 15.2.0, C++17.

## 자동 검증

- `build.ps1`: 게임 코어·랭킹·테스트를 빌드하고 **58개 테스트 통과, 실패 0개** 후 Windows GUI 실행 파일 빌드.
- 최종 GCC 빌드 옵션: `-std=c++17 -O2 -Wall -Wextra -Wpedantic -static -static-libgcc -static-libstdc++`. 최종 빌드 로그에 경고·오류 없음.
- CMake + Ninja Release 빌드 및 CTest: `rules_and_bonus` 통과. CTest 1개 항목 내부에서 동일한 58개 세부 사례를 실행.
- Windows 실행 파일의 DLL import를 확인해 GCC/MinGW 별도 DLL 없이 시스템 DLL로 동작하는지 점검.
- 코드 영역·함수 줄 번호는 `scripts/update_code_map.py`로 생성. README 링크의 파일 존재 및 줄 번호 범위 점검.

전체 세부 결과: [TEST_OUTPUT.txt](TEST_OUTPUT.txt), 최종 빌드 로그: [BUILD_LOG.txt](BUILD_LOG.txt). 개별 조건과 기댓값은 `tests/test_game.cpp`에 있음.

## 실제 Windows 창 확인

실행 파일을 Windows 데스크톱에서 직접 열고 키 입력과 실제 화면으로 확인했다.

| 항목 | 확인 내용 |
|---|---|
| 렌더링 | 3D 상자·구체, 명암, 바닥·석재·나무 질감, HUD. 보드 제목 겹침을 수정한 뒤 재확인 |
| 제목·모드 | 시작 화면, 1인 시작, 2인 시작과 각자 다른 HUD |
| 도움말 | F1 열기/닫기, 설명 영역의 잘림 여부 |
| P2 특수 키 | 오른쪽 Ctrl로 NORMAL→PIERCE→REMOTE, Enter로 설치 |
| P2 기폭·목숨 | Shift 기폭, BOMBS 1/1→0/1, 팀 목숨 3→2, 출발점 복귀 확인 |
| 시연 모드 | F3으로 준비된 배치를 호출. 2인 연습 출발점이 적과 겹치는 문제를 고친 뒤 T52와 실제 3목숨·폭탄 4/4 표시로 회귀 검증 |
| BFS 경로 | Chase 장면의 자홍색 최단 경로와 숫자 거리 표시를 실제 창에서 확인 |
| 랭킹 | Tab으로 빈 기록 안내 화면 확인. 연습 게임오버가 랭킹에 추가되지 않음 확인 |
| 화면 캡처 | F5로 front buffer 1280×900 BMP 저장, 이를 PNG로 변환한 실제 실행 화면이 `demo.png` |
| 종료·재실행 | Alt+F4로 닫은 뒤 다시 빌드·실행 |

자동 테스트는 게임 규칙에 대한 검사이다. 운영체제의 실제 스피커 출력 품질과 전체 3스테이지를 사람이 끝까지 플레이한 기록을 의미하지는 않는다. 소리는 실제 실행에 연결되어 있으며 M으로 음소거할 수 있다. 전체 스테이지 전환과 최종 승리의 상태 조건은 T41~42에서 검증한다. Visual Studio/MSVC 컴파일은 이 환경에서 별도 실행하지 않았다.
