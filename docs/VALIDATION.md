## 실제 Windows 창 확인

실행 파일을 Windows 데스크톱에서 직접 열고 키 입력과 실제 화면으로 확인했다.

| 항목 | 확인 내용 |
|---|---|
| 렌더링 | 3D 상자·구체, 명암, 바닥·석재·나무 질감, HUD. 보드 제목 겹침을 수정한 뒤 재확인 |
| 제목·모드 | 시작 화면, 1인 시작, 2인 시작과 각자 다른 HUD |
| 도움말 | F1 열기/닫기, 설명 영역의 잘림 여부 |
| P2 특수 키 | 오른쪽 Ctrl로 NORMAL→PIERCE→REMOTE, Enter로 설치 |
| P2 기폭·목숨 | Shift 기폭, BOMBS 1/1→0/1, 팀 목숨 3→2, 출발점 복귀 확인 |
| 시연 모드 | F3으로 준비된 배치를 호출. 2인 연습 출발점이 적과 겹치는 문제를 고친 뒤 T52와 실제 3목숨·폭탄 4/4 표시로 회귀 검증 |

| 화면 캡처 | F5로 front buffer 1280×900 BMP 저장, 이를 PNG로 변환한 실제 실행 화면이 `demo.png` |

자동 테스트는 게임 규칙에 대한 검사이다. 운영체제의 실제 스피커 출력 품질과 전체 3스테이지를 사람이 끝까지 플레이한 기록을 의미하지는 않는다. 소리는 실제 실행에 연결되어 있으며 M으로 음소거할 수 있다. 전체 스테이지 전환과 최종 승리의 상태 조건은 T41~42에서 검증한다. 이 절은 최초 3D 화면 확인 기록이며, 이후 Visual Studio 빌드와 새 UI 검증은 아래 절에 기록했다.
